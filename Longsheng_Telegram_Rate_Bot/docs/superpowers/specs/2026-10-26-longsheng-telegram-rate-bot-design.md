# 龙盛 Telegram 汇率做图机器人设计

## 目标

建立一个独立的「龙盛汇率做图助手」Telegram Bot。它只在一个由管理员指定的 Telegram 群中工作；群成员发送完整汇率文案后，机器人生成并回传一张固定龙盛黑金龙纹风格的高清汇率海报。

## 范围

- 一个独立 Telegram Bot。
- 严格以单一 `ALLOWED_CHAT_ID` 白名单限制使用范围；私聊、其他群和频道不响应。
- 固定龙盛视觉：黑金龙纹、吉隆坡夜景、蓝/绿/红三个汇率区块；马币与人民币合为一张竖版 PNG。
- 从标准中文文本解析日期、两项马币转账价、三项马币现金价、两项人民币价。
- 自动加入固定限制、Telegram 链接与客服账号。

## 非目标

- 不管理汇率或自动抓取市场价格。
- 不支持多个品牌、多群或用户自定义模板。
- 不允许群外成员调用或生成图片。

## 技术方案

- Python 3.12、aiogram 3 监听指定群消息。
- Pillow 使用一张龙盛模板背景与固定排版，将文字及数字以高分辨率绘制为 PNG；避免每次由 AI 重绘导致版式/文字不一致。
- Webhook 服务部署到 Render；Token、群 ID 与图片生成相关密钥全部使用环境变量，不写入代码或聊天记录。

## 使用方式

1. 在指定群发送整段“龙盛换汇｜每日汇率更新”文案。
2. Bot 校验群 ID 与格式。
3. Bot 回传海报；不符合格式时仅提示缺少字段。

## 已确认内容

- Bot 名称：龙盛汇率做图助手。
- 仅一个指定群可用。
- 该群内成员均可触发。
- 使用当前龙盛黑金龙纹模板，不自动切换视觉样式。
